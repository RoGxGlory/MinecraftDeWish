# Prototypes

Throwaway experiments that validate a mechanic or concept. Prototypes may skip production
standards, but:

- Each prototype lives in its own folder with a short `README.md` stating the hypothesis,
  how to run it, and the result.
- Prototype code must not be merged into `Source/` without a rewrite and a design review.
- Record the outcome in a playtest report (`/playtest-report`) or a concept doc
  (`/reverse-document`) before deleting the prototype.
