# Design

Studio-authored design documents live here. Existing project documentation remains in
`../Docs/` and is still the current source of truth.

- `gdd/` — game concept and per-system GDDs (`<system>.md`, 8 required sections)
- `narrative/` — story, lore, dialogue, character sheets
- `levels/` — level design documents and encounter layouts
- `balance/` — balance spreadsheets, curves, and tuning notes

Start with `/start`, `/project-stage-detect`, or `/map-systems`. Use `/design-system`
to author a GDD section by section, then `/design-review` before implementation.

Cross-reference the existing `Docs/GAME_DESIGN.md` and `Docs/SYSTEMS_REFERENCE.md`
instead of duplicating them.
