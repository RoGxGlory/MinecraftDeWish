# Production

Production artifacts live here. Nothing in this folder should duplicate design docs.

- `sprints/` — sprint plans and sprint reviews (`/sprint-plan`)
- `milestones/` — milestone definitions and reviews (`/milestone-review`)
- `releases/` — release checklists, launch checklists, patch notes (`/release-checklist`,
  `/launch-checklist`, `/patch-notes`)
- `session-state/` — ephemeral agent checkpoints (gitignored)
- `session-logs/` — ephemeral session audit trail (gitignored)

Use `/estimate`, `/retrospective`, `/scope-check`, and `/gate-check` to keep the plan honest.
